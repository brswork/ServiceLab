# ServiceLab - Готовый HTML/CSS/JS сайт

Это полностью конвертированная версия сайта ServiceLab без React.
Весь код написан на чистом HTML, CSS и JavaScript.

## 📁 Структура файлов

```
ready/
├── index.html          # Главный HTML файл со всем содержимым сайта
└── data/
    ├── styles.css      # Все стили (включая бывшие Tailwind классы)
    ├── script.js       # JavaScript с GSAP анимациями и интерактивностью
    └── logo.png        # Логотип компании
```

## 🚀 Запуск сайта

### Вариант 1: Простое открытие
Просто откройте файл `index.html` в браузере двойным кликом.

### Вариант 2: Локальный сервер (рекомендуется)
Для корректной работы всех функций лучше использовать локальный сервер:

**Python:**
```bash
cd ready
python -m http.server 8000
# Или для Python 2
python -m SimpleHTTPServer 8000
```

**Node.js (с установленным http-server):**
```bash
cd ready
npx http-server -p 8000
```

**PHP:**
```bash
cd ready
php -S localhost:8000
```

После запуска откройте браузер и перейдите по адресу: `http://localhost:8000`

## 🎨 Кастомизация

### Изменение цветов
Откройте `data/styles.css` и измените CSS переменные в `:root`:
```css
:root {
  --primary: 267 84% 57%;     /* Основной фиолетовый */
  --accent: 60 100% 50%;       /* Акцентный жёлтый */
  --secondary: 266 77% 75%;    /* Вторичный цвет */
  /* и т.д. */
}
```

### Изменение контента
Контент можно изменить двумя способами:

1. **В HTML** (`index.html`): Для статичного контента (Hero, About, Contact)
2. **В JavaScript** (`data/script.js`): Для динамического контента (массивы `services` и `approachCards`)

### Изменение анимаций
Все анимации находятся в `data/script.js` в функциях:
- `initHeroAnimations()` - анимации героя
- `initServicesAnimations()` - анимации услуг
- `initApproachAnimations()` - анимации подхода
- `initAboutAnimations()` - анимации "О нас"

## 📧 Форма контактов

Форма настроена с двумя вариантами работы:
1. Попытка отправки через API endpoint `/api/contact` (требует настройки бэкенда)
2. Fallback на mailto (открывает почтовый клиент пользователя)

Для настройки бэкенда отправки форм, создайте endpoint `/api/contact`, который принимает POST запросы с JSON:
```json
{
  "name": "Имя",
  "email": "email@example.com",
  "phone": "+7...",
  "message": "Сообщение"
}
```
